1. System Overview

ARB AI-Ops는 AWS 인프라 아키텍처의 안정성·보안·운영 적합성을 AI Agent로 자동 점검하는 시스템입니다.

ARB AI-Ops automatically inspects AWS infrastructure for stability, security, and operational readiness using AI Agents.


  • 기존 수작업(Wiki/Excel/이메일) 2~3일 → 30~60분 자동화
  • Manual process (Wiki/Excel/email) 2~3 days → 30~60 min automation
  • 인프라 체크리스트 75항목 + DB 체크리스트 214항목 자동 판정
  • 75 infra + 214 DB checklist items auto-evaluated
  • 645개 내부 운영 가이드 기반 RAG 채팅 제공
  • RAG chat powered by 645 internal operations guide docs
  • Web UI + Slack Bot 이중 채널 지원
  • Dual channel: Web UI + Slack Bot

❓ FAQ

Q. Role 이름을 변경해도 되나요? Q. Can I change the Role name?

아니요. ARB 자동화 도구가 ARB-ReadOnly-Role 이름을 기준으로 동작합니다.

No. The ARB automation tools rely on the exact name ARB-ReadOnly-Role.

Q. STEP 1에서 CREATE_FAILED가 발생합니다. Q. I get CREATE_FAILED in STEP 1.

동일 이름의 Role(ARB-ReadOnly-Role)이 이미 존재할 가능성이 높습니다. IAM 콘솔에서 확인 후 삭제하고 재시도하세요.

A Role named ARB-ReadOnly-Role likely already exists. Check IAM console, delete it if duplicate, and retry.

Q. ReadOnlyAccess 권한이 너무 넓은 건 아닌가요? Q. Isn't ReadOnlyAccess too broad?

ReadOnlyAccess는 모든 서비스의 조회(Get/List/Describe) 권한만 포함합니다. 쓰기/수정/삭제는 불가능하며, Trust Policy에 의해 ARB 팀 계정의 특정 Role만 Assume할 수 있습니다.

ReadOnlyAccess only includes Get/List/Describe across all services — no write, modify, or delete. The Trust Policy restricts access to only a specific ARB team Role.

Q. 리전을 추가로 배포해야 합니다. 처음부터 다시 해야 하나요? Q. I need to add another region. Do I start over?

아니요. 추가 리전에서 02-regional.yaml만 새로 배포하면 됩니다. 글로벌 스택은 그대로 유지됩니다.

No. Just deploy 02-regional.yaml in the new region. The global stack stays as-is.

5. 사전 서베이

5. Pre-Survey

AI Agent가 AWS API로 자동 수집하기 어려운 항목(예산 확보 여부, 테스트 결과, 운영 방식 등)을 ARB 점검 전에 미리 입력합니다. 저장된 서베이는 점검 시 자동 반영됩니다.

Pre-enter items that cannot be collected via AWS API (e.g. budget approval, test results, ops model). Saved responses are automatically applied during inspection.

13. 자주 묻는 질문 (FAQ)

13. Frequently Asked Questions

Q. 점검 시간이 얼마나 걸리나요?

Q. How long does an inspection take?

A. 일반적으로 30~60분 소요됩니다. 리전 수나 리소스 양에 따라 달라질 수 있습니다.

A. Typically 30~60 minutes, depending on the number of regions and resources.

Q. 같은 서비스를 하루에 여러 번 점검할 수 있나요?

Q. Can I inspect the same service multiple times per day?

A. 네, 가능합니다. 각 점검은 고유 ID로 분리 저장되어 이전 결과를 덮어쓰지 않습니다.

A. Yes. Each inspection is stored with a unique ID, so previous results are never overwritten.

Q. 채팅이 외부 인터넷 정보를 사용하나요?

Q. Does the chat use external internet information?

A. 아니요. 내부 645개 운영 가이드 문서와 점검 리포트만 참조합니다. 없으면 AWS 공식 지식으로 보완합니다.

A. No. Only internal 645 ops guide docs and inspection reports are used. AWS official knowledge supplements where needed.

Q. 사전 서베이를 반드시 작성해야 하나요?

Q. Is the pre-survey mandatory?

A. 아니요, 선택 사항입니다. 단, 입력 시 Agent의 판정 정확도가 향상됩니다 (예산, RTO/RPO, 테스트 결과 등).

A. No, it is optional. However, filling it in improves Agent accuracy for items like budget, RTO/RPO, and test results.
